# Sudoku Solver

This project is a C++ implementation of a Sudoku Solver using the Backtracking Algorithm.

## Features

- Solves any valid 9×9 Sudoku puzzle
- Accepts user input
- Uses recursive backtracking
- Displays the solved puzzle

## Language

- C++

## Algorithm

- Backtracking
